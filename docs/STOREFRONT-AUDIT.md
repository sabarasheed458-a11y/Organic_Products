# Storefront audit and refinements

Reviewed the original Maison Mira storefront against the shopping patterns on [mrlady.pk](https://mrlady.pk/): prominent campaigns, product-led discovery, repeated category collections, visible prices/discounts, and delivery/payment/policy information. The reference informed browsing priorities; its branding, photos, product descriptions, policies, and delivery promises were not imported.

The existing Next.js routes, Supabase clients, server checkout RPC, authentication, shopping persistence, admin, and database schema remain in place. No migration, seed change, dependency addition, deployment, or data mutation is part of this audit.

## Verification and limitations

Final local checks on 12 October 2026: strict TypeScript, lint without warnings, and production build passed; **16 unit tests, 18 embedded-database tests, and 27 production-browser tests passed**. Browser coverage includes desktop, tablet, mobile, and an additional 320 px viewport check. No new dependencies or migrations were needed.

The audit also fixed currency formatting that rounded fractional rupees. Prices now preserve up to two decimal places while whole-rupee prices remain clean; database paisa and checkout calculations are unchanged.

Meaningful regression coverage includes variant-price presentation, inactive/out-of-stock exclusions, valid sale labels, pagination beyond page 20, mobile account/search/Escape behavior, 320 px overflow, collapsed filters, and unavailable-item checkout blocking. Existing guest cart/wishlist persistence and public/protected-route browser tests are retained. Desktop/tablet/mobile screenshots are produced in ignored `artifacts/`.

No Supabase environment is configured in this checkout. Populated product-card and bag browser cases use explicit catalog API fixtures; authenticated checkout, actual uploaded photographs, category data, and scheduled banners require a configured staging store for live visual acceptance. Image presentation is improved, but no source photograph can be made sharper than its uploaded original. Upload licensed/original images at least 1200 px along the longest edge and review both full-length and detail shots. Do not use unrelated images to represent products.

The catalog's existing database price filters/sort continue to use product `effective_price`; card display additionally respects purchasable variant overrides. Changing database filtering to variant-level price ranges is a separate catalog-pricing decision and was not folded into this UI audit.
